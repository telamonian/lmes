lmes - Lattice Microbes with Enhanced Sampling

A stochastic simulation suite for Master Equation (ME) and Reaction-Diffusion Master Equation (RDME) simulations of biochemical systems. Optimized for AVX, CUDA, and running in parallel on thousands of machines. Now with enhanced sampling methods for even more speed (on the order of ~100X speedup for many simulations).

To use the enhanced sampling functionality, see the [user guide](https://raw.githubusercontent.com/telamonian/jhu-thesis-template/refs/heads/master/docs/lmes_enhanced_sampling.pdf) in the docs folder of this repo.

The enhanced sampling was done as part of the thesis work of Max Klein, PhD. See [my thesis](https://raw.githubusercontent.com/telamonian/jhu-thesis-template/refs/heads/master/the_thesis.pdf) for more details.
